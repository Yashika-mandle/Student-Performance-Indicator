# 📊 Student Performance Indicator

A Machine Learning-based web application that analyzes student academic and demographic factors to predict student performance. The project implements an end-to-end ML workflow from data preprocessing and model training to prediction through a Flask web application.

## 🚀 Features

- 📊 Exploratory Data Analysis (EDA)
- 🧹 Data preprocessing and feature engineering
- 🤖 Multiple Machine Learning models
- 📈 Model evaluation and comparison
- 🏆 Best model selection
- 🔄 Prediction pipeline
- 🌐 Flask-based web application
- ⚡ Real-time student performance prediction

## 🛠️ Tech Stack

- **Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn, XGBoost
- **Web:** Flask, HTML, CSS
- **Tools:** Jupyter Notebook, Git, GitHub

## 🧠 ML Workflow

```text
Dataset

   ↓

   ↓

   ↓

   ↓
Model Evaluation
   ↓

   ↓
Prediction Pipeline

   ↓

```

## 📊 Machine Learning

The project explores multiple Machine Learning algorithms and evaluates their performance using appropriate metrics. The best-performing model is integrated into the final prediction pipeline.
